# OrbitalIDE

Трёхмерный файловый менеджер с встроенным редактором кода. Работает с **настоящей
папкой на диске**: всё, что вы создаёте, переименовываете или удаляете в 3D-сцене,
сразу происходит в файловой системе. Редактор читает и сохраняет реальные файлы.

## Запуск

Зависимостей нет — нужен только Python 3.9+.

```bash
cd OrbitalIDE
python3 run.py
```

При запуске скрипт спросит:

1. где создать папку проекта (по умолчанию `~/Desktop`);
2. как назвать папку (по умолчанию `OrbitalProject`).

После этого создаётся пустая рабочая папка, запускается локальный сервер на
`127.0.0.1` и открывается браузер. В сцене изначально нет ни файлов, ни папок —
только корень проекта.

### Без интерактивных вопросов

```bash
python3 run.py --workspace ~/Desktop/MyProject
python3 run.py --workspace . --port 9000 --no-browser
```

Параметры:

- `--workspace PATH` — рабочая папка (создаётся при необходимости);
- `--port N` — стартовый порт, по умолчанию `8000` (если занят, берётся следующий);
- `--no-browser` — не открывать браузер автоматически.

Остановка — `Ctrl+C` в терминале.

## Управление

- **ЛКМ по узлу** — открыть папку или файл в редакторе.
- **Перетаскивание узла** — оттянуть его от орбиты (пружины вернут обратно).
- **ПКМ по пустому месту** — создать папку/файл, обновить дерево с диска.
- **ПКМ по узлу** — открыть, переименовать (`F2`), удалить.
- **Колесо мыши** — масштаб.
- **Alt+← / Backspace** — на уровень выше.
- **Ctrl+S** — сохранить открытый файл (есть автосохранение через 0,9 с).
- **Esc** — закрыть меню/модалку/редактор.

Новые файлы создаются пустыми. Цвет и форма узла зависят от расширения:
`.py`, `.cpp`, `.js`, `.html`, `.css`, `.json`, `.md` и другие подсвечиваются
в редакторе соответствующим режимом CodeMirror.

## Что происходит на диске

- Дерево в сцене — это содержимое выбранной рабочей папки.
- Создание, переименование и удаление выполняются через локальный API и реальные
  файловые операции.
- Кнопка `⟲` в шапке перечитывает папку с диска — удобно, если файлы изменили
  снаружи (например, в другом редакторе).
- Служебные каталоги (`.git`, `node_modules`, `__pycache__`, `.venv`, `dist`,
  `build` и т. п.) не показываются.
- Символические ссылки не поддерживаются и не показываются.
- Файлы больше 2 МБ и бинарные файлы в редакторе не открываются.

## Структура проекта

```text
OrbitalIDE/
├── run.py          # Python-сервер, API и выбор рабочей папки
├── index.html      # разметка интерфейса
├── style.css       # оформление сцены, меню, модалок и редактора
├── app.js          # Three.js-сцена, физика, UI и работа с API
└── vendor/         # локальные Three.js, OrbitControls, CodeMirror и режимы
```

## API

Сервер слушает только `127.0.0.1`.

| Метод | Путь | Назначение |
| --- | --- | --- |
| `GET` | `/api/info` | имя и путь рабочей папки |
| `GET` | `/api/tree` | дерево файлов и папок |
| `GET` | `/api/read?path=...` | прочитать файл |
| `POST` | `/api/create` | создать папку или файл |
| `POST` | `/api/rename` | переименовать |
| `PUT` / `POST` | `/api/write` | сохранить файл |
| `DELETE` | `/api/delete` | удалить файл или папку |

Пути в API — относительные, от корня рабочей папки; корень обозначается `"."`.
Выход за пределы рабочей папки и символические ссылки запрещены.
